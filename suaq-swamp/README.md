# Suaq Swamp Dashboard

**Not added yet.** The file wasn't to hand when this repo was scaffolded.

To add it:

1. Rename the dashboard HTML to `index.html` and put it in this folder.
2. Upload it (GitHub → this folder → **Add file → Upload files**), with a commit
   message like `Add Suaq Swamp dashboard`.
3. Edit the top-level `README.md` and `index.html` to turn the placeholder row into
   a real link — in `index.html`, remove `off` from that card's `class` and delete
   the `not added yet` tag.
4. Replace this file with a short description: what the dashboard shows, what data
   it expects, and anything a first-time user would otherwise get wrong.

If the dashboard loads data from separate files rather than embedding it, put
those alongside `index.html` and make sure the paths in the HTML are relative
(`data/sites.json`, not `/Users/ben/...`), or it will work on your machine and
nowhere else.
