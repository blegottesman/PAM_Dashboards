Bioacoustics Dashboards

Small browser tools for passive acoustic monitoring. Each one is a single HTML file that runs offline. Your audio is read from your own disk and never leaves your machine.

Tools

BirdNET Validatorv1.0.0
Review BirdNET detections one class at a time, label true and false positives with hotkeys, and fit the confidence threshold that buys a target precision. Clips are cut on demand from hour-long recordings.
open →
Clip Reviewer
Lightweight one-at-a-time labeller for a folder of pre-cut segments.
open →
Amakihi Meme Explorer
Song-type structure and sharing across Hawaiʻi ʻAmakihi recordings. The dataset is embedded, so the page is large but needs nothing else.

Duke Farms Detection ExplorerR / Shiny
Spatial and temporal exploration of BirdNET detections. Runs in R rather than the browser, so it is downloaded and run locally.
how to run →
Browser support. Opening whole folders of audio needs the File System Access API, which ships in Chrome, Edge, Opera and Arc but not Safari or Firefox. The tools still work there — audio comes in through a file picker instead — but for hour-long archives Chrome or Edge is markedly less painful.
