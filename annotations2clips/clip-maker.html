How it works

Your recordings never leave your computer

This page has no server. When you choose a folder, the browser is given permission to read those files, and Clip Maker reads only the few seconds it needs for each clip. Nothing is uploaded or copied. The clips are written straight to the folder you pick in step 7.

Which browsers can work with folders

Chrome, Edge, Opera, Arc and Brave can open a whole folder of recordings, including its subfolders, with one permission prompt, and can write clips straight into a folder you choose.

Safari and Firefox can also open a folder, but cannot write into one. In those browsers the clips come down as a single ZIP download. That is fine for a few hundred clips and slow for thousands.

How Raven records time, and why that matters

A Raven selection table starts out with just Begin Time, End Time, Low Frequency, High Frequency and your annotation columns. When you open more than one file in Raven, it stitches them into one long timeline, so Begin Time is measured from the start of the first file that was open, not the start of the file the sound is actually in.

Raven can add Begin File, Begin Path and File Offset columns (in the selection table's column settings). File Offset says how far into its own file each sound is, which is exactly what is needed to cut a clip. Many tables have them; many don't.

  • With File Offset — each sound is located directly. Nothing to work out.
  • Without it — Clip Maker lines up your recordings in the order Raven opened them, adds up their lengths, and works out which file each Begin Time lands in. This only works if the folder holds exactly the files that were open in Raven. If the table also has Begin File, that column is used to double-check the answer.

A selection that runs past the end of its recording is joined with the start of the next recording in the sequence, so the clip is complete.

Several tables, and recordings with the same name

Drop several tables in step 1 and their rows are combined. A {table} name part is available so clips can carry the name of the table they came from. Each table is located independently, so one can have File Offset and another not.

If two recordings in different subfolders share a file name (common when several sites use the same recorder schedule), Clip Maker uses the table's Begin Path column to tell them apart. Without that column it takes the first match and warns you.

What is remembered between visits

Your naming pattern, settings and language are kept in this browser, and so are the last recordings folder and output folder, so the next table takes two clicks. Nothing is sent anywhere. clears it.

About the code

Clip Maker is one self-contained web page: HTML for the layout, CSS for the look, and JavaScript for everything it does. There is no server, no install, no library and no internet connection needed — the file works from a hard drive, a USB stick, a shared folder or a website.

  • It reads WAV and FLAC headers itself and copies only the bytes a clip needs, so cutting a WAV is exact and fast.
  • FLAC is decoded by the browser's own audio engine (the Web Audio API), which also handles resampling.
  • Folder access and saving use the browser's File System Access API; where that is missing, a ZIP is built in the page.
  • Spectrograms are a short-time Fourier transform drawn on a canvas element.

The code was written by Claude, an AI model made by Anthropic, and was designed, specified and customised by Benjamin Gottesman (K. Lisa Yang Center for Conservation Bioacoustics, Cornell Lab of Ornithology) for the people who work with Raven selection tables every day. The source is readable in any text editor — it is meant to be changed.

The clips.csv list and README

One row per clip: the clip's file name and folder, the recording it was cut from, where in that recording it starts and ends, the table it came from, and every column of the original selection. It is the record of what was made, and it is the file to hand to a script or a model later. README.txt beside it records which tables, which settings and which version made the clips.
